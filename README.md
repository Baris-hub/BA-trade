# BA Trade - International Trade Solutions

A modern, responsive, and animated single-page website for an international trade and logistics company.

## Tech Stack
- HTML5
- CSS3 (Custom animations, Flexbox, Grid, CSS Variables)
- Vanilla JavaScript (Intersection Observer for scroll animations)
- Phosphor Icons / FontAwesome (Icons)
- Google Fonts (Inter & Playfair Display)

## Project Structure
```
ba-trade/
├── css/
│   ├── style.css       # Main stylesheet (layout, typography, colors)
│   └── animations.css  # Keyframes and animation classes
├── js/
│   └── main.js         # Scroll animations, mobile menu, interactions
├── index.html          # Main HTML structure
├── favicon.svg         # SVG Favicon
├── manifest.json       # Web App Manifest
├── robots.txt          # SEO rules
├── sitemap.xml         # XML Sitemap
└── README.md           # Project documentation
```

## How to Run
1. Clone or download this repository.
2. Open `index.html` directly in your web browser.
3. For a better development experience (with auto-reload), use the VS Code extension "Live Server":
   - Open the project folder in VS Code.
   - Right-click `index.html` and select "Open with Live Server".

## How to Customize Content
- **Text & Images**: Edit the content directly within `index.html`.
- **Colors & Typography**: Modify the CSS variables at the top of `css/style.css` in the `:root` pseudo-class.
- **Animations**: Adjust animation timings, delays, and keyframes in `css/animations.css`.
